# cakewalk documentation site

Source for <https://vxlk.github.io/cakewalk/>, built with [Docusaurus](https://docusaurus.io/).

The prose lives in [`docs/`](./docs). Everything else is scaffolding.

## Local development

```bash
npm install
npm start
```

Serves at `http://localhost:3000/cakewalk/` with live reload.

## Build

```bash
npm run build
npm run serve   # preview the production build
```

`onBrokenLinks` is set to `throw`, so a broken internal link fails the build rather than shipping.

## Deployment

Pushing to `master` triggers [`.github/workflows/docs.yml`](../.github/workflows/docs.yml), which builds and publishes to GitHub Pages. There is no manual deploy step.

## Adding a page

Add a Markdown file to `docs/` with front matter:

```yaml
---
id: my-page
title: My page
sidebar_position: 8
---
```

Then list its `id` in [`sidebars.js`](./sidebars.js) — the sidebar is explicit rather than autogenerated, so page order is deliberate.

## A note on the content

The performance claims in these docs are load-bearing, and several of them are deliberately hedged: some numbers are measured, and some are extrapolation from measured seek counts. If you change a benchmark figure, keep that distinction intact — the value of the [performance page](./docs/performance.md) is that a reader can tell which is which.
